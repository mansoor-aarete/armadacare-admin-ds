## Source and licence

Sprites (`<use href>`) are not used because Figma Make cannot serve static sprite files.

## Usage
```tsx
<Icon name="standard:account" size="small" assistiveText="Account" />
<Icon name="utility:info" size="x-small" tone="default" assistiveText="More information" />
<Icon name="utility:check" size="x-small" tone="current" />   // decorative, inherits text colour
```
Inside other blueprints (buttons, inputs) use `IconSvg` with the blueprint's own class (e.g. `slds-button__icon`).

## Sizes
`xx-small` 0.875rem · `x-small` 1rem · `small` 1.5rem · `medium` 2rem (default) · `large` 3rem.

## Tones (utility only)
`default` (`slds-icon-text-default`) · `light` · `warning` · `error` · `success` · `current` (`slds-current-color`) · `inverse` (no tone class — white glyph on a coloured surface, e.g. the error popover header).

## Adding an icon
1. Confirm it appears in Figma / the inventory. 2. Add `[sprite, name, evidence]` to `ICONS` in `scripts/build-icons.mjs`. 3. `npm run icons` → `npm run verify` → `npm run typecheck`. 4. Update this list.

## Do / Don't
- **Do** pass `assistiveText` unless the icon is purely decorative next to visible text.
- **Don't** import SVG files, use icon fonts, other icon libraries (lucide, MUI), or recolour object icons (the only exception is `standard:user`, themed in `slds-theme.css`).

## Container classes
Object icons: `slds-icon-standard-team-member` (underscores → hyphens, as the SLDS CSS defines them). Utility icons: `slds-icon-utility-{raw symbol name}` (e.g. `slds-icon-utility-filterList`) — blueprint markup only, no CSS; allowed via the pattern in `scripts/slds-markup-only.json`.
